## 📏 精确尺寸规划

### 整体布局
- **窗口总尺寸**: 1400px × 900px
- **菜单栏**: 1400px × 30px
- **内容区域**: 1400px × 840px (去除菜单栏和状态栏)
- **状态栏**: 1400px × 30px

### 区域1: 图像导入与角度配置 (1380px × 200px)
- **图像卡片**: 100px × 100px × 10张 = 1000px宽度
- **按钮区域**: 200px宽度 (导入图像、生成SDF按钮)
- **角度输入**: 每张图下方显示角度输入框和删除按钮
- **进度条**: 1360px × 20px (生成时显示)
- **边距**: 左右各10px

### 区域2: 单张SDF结果 (1380px × 150px)
- **SDF预览**: 100px × 100px × 10张
- **状态显示**: 每张SDF下方显示生成状态和耗时
- **对齐**: 与上方图像卡片完全对齐

### 区域3: 合并SDF预览 (680px × 400px)
- **预览图像**: 660px × 350px (支持缩放拖拽)
- **控制区域**: 660px × 50px
  - 缩放按钮: [适应][1:1][重置] + 缩放百分比显示
  - 混合模式: 下拉选择框

### 区域4: 光照效果预览 (680px × 400px)
- **预览图像**: 660px × 300px (固定显示)
- **控制区域**: 660px × 100px
  - 光照角度滑竿 + 数值显示
  - 光照强度滑竿 + 数值显示  
  - 环境光滑竿 + 数值显示

## 🎯 关键设计要点

### 1. 图像卡片设计
```
┌─────────────┐
│   缩略图     │ 100px × 100px
│   (100×100)  │
├─────────────┤
│ filename.png │ 文件名 (截断显示)
├─────────────┤
│ 角度: [45°]  │ 可编辑输入框
├─────────────┤
│    [×删除]   │ 删除按钮
└─────────────┘
```

### 2. SDF结果卡片设计
```
┌─────────────┐
│   SDF预览    │ 100px × 100px
│   (灰度图)   │
├─────────────┤
│  ✓ 0.12s    │ 状态 + 耗时
└─────────────┘
```

### 3. 进度条设计
- **显示时机**: 点击"生成SDF"后显示
- **进度内容**: "正在生成SDF... (3/10)"
- **颜色**: 蓝色进度条 + 百分比文字

### 4. 控制面板设计
- **紧凑布局**: 所有控件在一行内显示
- **实时反馈**: 滑竿拖动时实时更新预览
- **数值显示**: 滑竿旁边显示当前数值

## 🔧 技术实现要点

1. **固定窗口**: `setFixedSize(1400, 900)`
2. **图像限制**: 导入时检查数量，最多10张
3. **自动角度**: 导入时自动分配 `360° / 图像数量`
4. **进度更新**: 使用QProgressBar + 信号槽机制
5. **布局管理**: 使用QHBoxLayout + QVBoxLayout组合

## 🚀 开发优先级

### Phase 1: 基础布局
1. 创建固定窗口和四个主要区域
2. 实现图像卡片组件
3. 实现SDF结果卡片组件

### Phase 2: 核心功能
1. 图像导入和角度配置
2. 单张SDF生成和显示
3. 进度条显示

### Phase 3: 预览功能
1. 合并SDF预览(支持缩放拖拽)
2. 光照效果预览(固定显示)
3. 参数控制面板

### Phase 4: 完善功能
1. 导出功能
2. 错误处理
3. 用户体验优化
