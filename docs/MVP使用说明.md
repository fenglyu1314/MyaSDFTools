# SDF工具 MVP版本使用说明

## 🎉 恭喜！MVP版本已完成

您的SDF工具MVP版本已经成功搭建并可以运行！这个版本包含了所有基础功能，可以进行实际的SDF生成和测试。

## 🚀 快速开始

### 1. 启动应用程序

```bash
# 在项目根目录下运行
python main.py
```

### 2. 基本使用流程

1. **导入图像**
   - 点击"导入图像"按钮选择图像文件
   - 或直接拖拽图像文件到图像列表区域
   - 支持格式：PNG, JPG, JPEG, BMP, TGA

2. **调整参数**
   - 在左侧参数面板中调整SDF生成参数
   - 二值化阈值：控制黑白分界线
   - 归一化：将结果映射到[0,1]范围
   - 算法选择：目前使用Python实现

3. **生成SDF**
   - 点击"生成SDF"按钮开始计算
   - 等待计算完成（会显示进度条）
   - 查看右侧预览区域的结果

4. **预览和调整**
   - 使用光照角度滑竿预览不同角度的效果
   - 调整缩放比例查看细节
   - 可选择显示网格辅助线

5. **导出结果**
   - 点击"导出SDF"按钮
   - 选择保存位置和格式
   - 支持PNG、JPEG、TIFF格式

## 🎯 使用建议

### 图像准备

1. **推荐格式**：PNG（无损压缩）
2. **推荐尺寸**：512x512 或 1024x1024
3. **图像类型**：黑白图或灰度图
4. **内容要求**：清晰的明暗对比

### 参数调整

1. **二值化阈值**
   - 0.5：标准阈值，适合大多数情况
   - 调低：更多区域被视为"内部"
   - 调高：更少区域被视为"内部"

2. **算法选择**
   - 8SSEDT：推荐，速度快质量好
   - 其他算法：实验性功能

3. **质量设置**
   - 平衡：推荐设置
   - 高质量：计算时间更长但结果更精确

### 性能优化

1. **图像尺寸**：较大图像计算时间更长
2. **内存使用**：注意内存限制设置
3. **线程数**：保持自动检测即可
