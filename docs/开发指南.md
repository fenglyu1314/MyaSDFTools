### 整体架构

```
┌─────────────────┐    ┌─────────────────┐
│   PySide6 UI    │    │   Python Core   │

└─────────────────┘    └─────────────────┘

                       ┌─────────────────┐
                       │   C++ Engine    │
```

### 模块职责

#### UI层 (`src/ui/`)
- **MainWindow**: 主窗口框架
- **ImageListWidget**: 图像列表管理
- **PreviewWidget**: SDF预览显示
- **ParameterWidget**: 参数控制面板

#### 核心层 (`src/core/`)
- **SDFGenerator**: SDF生成器，封装算法调用
- **ImageManager**: 图像数据管理
- **ConfigManager**: 配置管理

#### 算法层 (`src/cpp/`)
- **sdf_algorithms.cpp**: 8SSEDT算法实现
- **sdf_core.cpp**: Python接口封装
- **bindings.cpp**: pybind11绑定

#### 工具层 (`src/utils/`)
- **FileUtils**: 文件操作
- **ImageUtils**: 图像处理
- **MathUtils**: 数学计算

```python
class SDFComputeThread(QThread):
    progress_updated = Signal(int)
    computation_finished = Signal(object)

        super().__init__()
        self.images = images
        self.angles = angles
```

### 计算时间统计
```python
import functools
import time

def timing_decorator(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        end = time.perf_counter()
        
        print(f"{func.__name__}: {end - start:.3f}s")
        return result
    return wrapper
```
