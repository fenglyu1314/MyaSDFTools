# 预览功能改进说明

## 🎯 问题解决

您提出的问题："现在生成的预览图尺寸太大了，在预览窗口里只能看到一个局部，应该增加缩放和拖动的功能" 已经完全解决！

## ✨ 新增功能

### 1. 🔍 智能缩放系统

#### 自适应显示
- **自动适应窗口**: 图像首次加载时自动缩放到合适大小
- **保持完整可见**: 确保整个图像在预览窗口中完全可见
- **动态调整**: 窗口大小改变时自动重新计算缩放比例

#### 手动缩放控制
- **滑竿控制**: 10% - 500% 精确缩放控制
- **鼠标滚轮**: 以鼠标位置为中心进行缩放
- **快捷按钮**: 
  - "适应窗口" - 自动适应当前窗口大小
  - "实际大小" - 100% 原始尺寸显示
  - "重置视图" - 恢复到初始状态

### 2. 🖱️ 拖拽移动系统

#### 鼠标拖拽
- **左键拖拽**: 按住左键拖动图像到任意位置
- **实时移动**: 拖拽过程中实时更新图像位置
- **光标提示**: 拖拽时显示抓手光标

#### 智能边界
- **无限制移动**: 可以将图像拖拽到任意位置
- **中心对齐**: 重置时自动回到窗口中心

### 3. 🎛️ 增强的控制界面

#### 新增控制按钮
```
[适应窗口] [实际大小] [重置视图]
```

#### 改进的缩放滑竿
- **实时同步**: 鼠标滚轮缩放时自动更新滑竿位置
- **精确显示**: 显示当前缩放百分比
- **范围扩大**: 支持 10% - 500% 缩放范围

#### 用户提示
- **操作指南**: 界面底部显示操作提示
- **状态反馈**: 实时显示当前操作状态

## 🔧 技术实现

### 核心改进

1. **PreviewImageWidget 重构**
   - 添加鼠标事件处理 (拖拽、滚轮)
   - 实现智能缩放算法
   - 支持偏移量计算和显示

2. **自适应显示算法**
   ```python
   def _fit_to_window(self):
       scale_x = available_width / image_width
       scale_y = available_height / image_height
       zoom_factor = min(scale_x, scale_y, 1.0)  # 不超过100%
   ```

3. **鼠标滚轮缩放**
   - 以鼠标位置为缩放中心
   - 保持鼠标指向的图像区域不变
   - 平滑的缩放体验

4. **拖拽系统**
   - 记录鼠标按下位置
   - 计算移动偏移量
   - 实时更新图像显示位置

### 事件处理

```python
# 鼠标事件
- mousePressEvent()    # 开始拖拽
- mouseMoveEvent()     # 拖拽移动
- mouseReleaseEvent()  # 结束拖拽
- wheelEvent()         # 滚轮缩放
- resizeEvent()        # 窗口大小改变
```

## 🎮 使用方法

### 基本操作

1. **查看完整图像**
   - 图像加载后自动适应窗口大小
   - 点击"适应窗口"按钮随时恢复

2. **放大查看细节**
   - 使用鼠标滚轮放大到感兴趣的区域
   - 或拖动缩放滑竿到合适的比例

3. **移动查看不同区域**
   - 按住左键拖拽图像到任意位置
   - 查看图像的不同部分

4. **快速重置**
   - 点击"重置视图"回到初始状态
   - 点击"实际大小"查看100%尺寸

### 高级技巧

1. **精确缩放**
   - 将鼠标移动到要放大的区域
   - 使用滚轮以该点为中心缩放

2. **快速导航**
   - 先"适应窗口"查看全貌
   - 再放大到感兴趣的区域
   - 用拖拽浏览不同部分

3. **对比查看**
   - 使用"实际大小"查看原始细节
   - 切换到"适应窗口"查看整体效果
