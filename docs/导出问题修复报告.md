# SDF工具导出问题修复报告

## 问题概述

用户反馈了两个关键问题：
1. **导出图像和预览不一致**：导出的图像是彩色的（三个通道值不同），而预览显示的是灰度图像
2. **打开目录功能错误**：导出后选择打开目录时，打开的不是保存图片的正确目录

## 问题分析

### 问题1：导出图像颜色不一致

**根本原因**：
- 预览时：使用 `_numpy_to_pixmap()` 方法，将SDF数据转换为灰度图像显示
- 导出时：使用 `ImageUtils.save_sdf_as_image()` 方法，默认参数 `colormap='viridis'`，将SDF数据转换为彩色图像

**具体位置**：
- `src/ui/main_window.py` 第1217行：单个SDF导出
- `src/ui/main_window.py` 第1580行：批量SDF导出
- `src/utils/image_utils.py` 第276行：`save_sdf_as_image` 方法默认参数

### 问题2：打开目录功能错误

**根本原因**：
- Windows系统下的explorer命令调用方式不正确
- 路径处理和引号使用有问题
- 缺少错误处理和备用方案

## 修复方案

### 修复1：统一导出和预览的颜色模式

**修改内容**：
1. 在单个SDF导出时，明确指定 `colormap='gray'`
2. 在批量SDF导出时，明确指定 `colormap='gray'`

**修改内容**：
1. 使用绝对路径解析，避免路径问题
2. 改进Windows系统下的explorer命令调用方式
3. 添加备用方案：使用webbrowser模块作为fallback
4. 增强错误处理和日志输出

**修改位置**：

## 技术细节

### 颜色映射说明
- `colormap='gray'`：生成灰度图像，模式为'L'
- `colormap='viridis'`：生成彩色图像，模式为'RGB'
- SDF数据本质上是距离场，使用灰度显示更符合数据特性

### 文件夹打开机制
1. **主要方案**：使用系统原生命令
   - Windows: `explorer /select,"文件路径"`
   - macOS: `open -R 文件路径`
   - Linux: `xdg-open 文件夹路径`

2. **备用方案**：使用Python webbrowser模块
   - 当系统命令失败时自动启用
   - 通过file://协议打开文件夹
