# SDF工具用户手册

## 📖 概述

SDF工具是一个专为二次元渲染设计的脸部SDF (Signed Distance Field) 生成工具。它可以将黑白图像转换为SDF格式，支持多角度光照图像混合，并提供实时预览功能。

## 🚀 快速开始

### 启动应用

```bash
# 方式1: 直接启动
python main.py

# 方式2: 快速启动脚本
python quick_start.py
```

### 基本工作流程

1. **导入图像**: 点击"导入图像"按钮，选择一张或多张黑白图像
2. **配置角度**: 为每张图像设置对应的光照角度
3. **生成SDF**: 点击"生成SDF"按钮开始计算
4. **预览效果**: 使用滑竿调整光照角度，实时预览效果
5. **导出结果**: 点击"导出"按钮保存SDF图像

## 🖥️ 界面介绍

### 主界面布局

应用界面分为5个主要区域：

1. **图像导入区域** (左上): 显示已导入的图像和角度配置
2. **SDF结果区域** (左中): 显示每张图像的SDF生成结果
3. **参数控制区域** (左下): SDF生成参数和混合模式设置
4. **合并SDF预览** (右上): 显示混合后的SDF结果，支持缩放拖拽
5. **光照效果预览** (右下): 实时显示光照效果

### 功能按钮

- **导入图像**: 选择要处理的图像文件
- **生成SDF**: 开始SDF计算过程
- **导出**: 保存SDF结果到文件
- **适应窗口**: 将预览图像缩放到适合窗口大小
- **实际大小**: 显示图像的原始大小
- **重置视图**: 重置预览区域的缩放和位置

## ⚙️ 参数说明

### SDF生成参数

- **阈值 (Threshold)**: 二值化阈值，范围0.0-1.0，默认0.5
- **归一化 (Normalize)**: 是否将SDF结果归一化到[0,1]范围
- **反转 (Invert)**: 是否反转SDF的内外区域

### 混合模式

- **加权混合 (Weighted)**: 根据角度权重混合，推荐用于光照效果
- **平均混合 (Average)**: 简单平均所有SDF
- **最大值 (Max)**: 取所有SDF的最大值
- **最小值 (Min)**: 取所有SDF的最小值

### 光照控制

- **光照角度**: 0-360度，控制光照方向
- **光照强度**: 0.1-3.0，控制光照强度
- **环境光**: 0.0-1.0，控制环境光强度

## 💡 使用技巧

### 图像准备
1. **使用黑白图像**: 确保输入图像是灰度或黑白图像
2. **清晰的边界**: 图像应有清晰的黑白边界，避免过多灰度过渡
3. **合适的分辨率**: 推荐512x512到2048x2048像素

### 角度设置
1. **均匀分布**: 多张图像的角度应尽量均匀分布
2. **覆盖范围**: 建议覆盖0-360度的完整范围
3. **关键角度**: 重点关注0°、90°、180°、270°等关键角度

### 性能优化
1. **图像尺寸**: 较大图像需要更多计算时间和内存
2. **C++后端**: 如果可用，C++后端可显著提升性能
3. **内存管理**: 处理大量图像时注意内存使用

## 🔧 故障排除

### 常见问题

**Q: 导入图像后无法生成SDF？**
A: 检查图像格式是否支持，确保图像文件未损坏

**Q: SDF生成速度很慢？**
A: 尝试减小图像尺寸，或检查是否启用了C++后端

**Q: 预览效果不理想？**
A: 调整阈值参数，或检查输入图像的质量

**Q: 程序崩溃或无响应？**
A: 检查内存使用情况，尝试处理较小的图像

### 错误信息

- **"图像加载失败"**: 检查文件路径和格式
- **"SDF计算失败"**: 检查图像内容和参数设置
- **"内存不足"**: 减小图像尺寸或关闭其他程序
