## 🐛 已知问题

### 当前限制
1. **C++后端**: 尚未实现，使用Python版本 (性能较低)
2. **多角度混合**: 算法较简单，可进一步优化
3. **实时预览**: 光照效果模拟较基础
4. **批量处理**: 暂不支持批量操作

### 性能限制
- **计算速度**: Python实现，大图像较慢
- **内存占用**: 大图像可能占用较多内存
- **并发处理**: 暂不支持多任务并行

## 🚀 启动指南

### 环境要求
- Python 3.8+
- Windows 10+ / Linux / macOS
- 4GB+ RAM (推荐8GB)

### 快速启动
```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行测试
python test_mvp.py

# 3. 启动应用
python main.py
```
