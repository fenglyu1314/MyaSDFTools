# SDF工具需求文档

## 项目概述

**项目名称**: 二次元脸部SDF生成工具  
**技术栈**: Python (PySide6) + C++ (核心算法)  
**目标用户**: 二次元渲染艺术家、技术美术  

## 核心功能需求

### 1. 多角度脸部SDF生成 (主要功能)

#### 1.1 输入管理
- **多图导入**: 支持导入N张黑白脸部光照图像
- **拖拽排序**: 可通过拖拽调整图像顺序
- **格式支持**: PNG、JPG、TGA等常见图像格式
- **预览显示**: 缩略图网格显示，支持删除和替换

#### 1.2 角度配置
- **自动计算**: 根据导入图像数量自动分配光照角度 (360°/N)
- **手动调整**: 每张图可独立设置光照角度值
- **角度验证**: 检查角度覆盖范围，提示缺失区域
- **实时更新**: 角度修改后实时更新预览效果

#### 1.3 SDF生成
- **算法**: 使用8SSEDT算法进行SDF计算
- **混合策略**: 基于SDF特性的帧间插值混合
- **性能监控**: 显示计算耗时和进度条
- **结果输出**: 生成最终SDF贴图文件

### 2. 单张图SDF生成 (基础功能)

- **快速转换**: 单张黑白图直接生成SDF
- **参数调整**: 可调整SDF生成参数
- **对比显示**: 原图与SDF结果对比

### 3. 实时预览系统

#### 3.1 SDF效果预览
- **2D预览窗口**: 实时显示SDF计算结果
- **光照模拟**: 滑竿控制光照角度 (0-360°)
- **插值效果**: 显示当前角度的插值光照效果
- **缩放平移**: 支持预览窗口的缩放和平移操作

#### 3.2 对比功能
- **分屏显示**: 原始关键帧 vs SDF插值结果
- **切换模式**: 快速切换不同预览模式

### 4. 用户界面设计

#### 4.1 主界面布局
```
┌─────────────────┬─────────────────┐
│   图像导入区域    │    SDF预览区域   │
│  (缩略图网格)    │   (实时预览)    │
├─────────────────┼─────────────────┤
│   角度配置面板    │    参数控制区    │
│  (角度输入框)    │   (滑竿+按钮)   │
└─────────────────┴─────────────────┘
```

#### 4.2 交互控件
- **导入按钮**: 批量导入图像文件
- **生成按钮**: 执行SDF计算
- **导出按钮**: 保存SDF结果
- **角度滑竿**: 预览光照效果
- **进度条**: 显示计算进度
- **状态栏**: 显示计算时间和状态信息

## 技术规格

### 1. 性能要求
- **计算效率**: C++核心算法，支持多线程
- **内存管理**: 大图像的流式处理
- **响应速度**: UI操作响应时间 < 100ms

### 2. 算法规格
- **SDF算法**: 8SSEDT (8-point Sequential Signed Distance Transform)
- **插值方法**: 基于SDF距离场的权重插值
- **归一化**: 输出范围映射到 [0,1]

### 3. 文件格式
- **输入格式**: PNG, JPG, TGA, BMP
- **输出格式**: PNG (16-bit), EXR, TGA
- **项目文件**: JSON格式保存配置

## 验收标准

1. **功能完整性**: 所有核心功能正常工作
2. **性能指标**: 512x512图像SDF生成时间 < 1秒
3. **用户体验**: 界面友好，操作直观
4. **稳定性**: 无崩溃，内存泄漏 < 1MB/小时
5. **兼容性**: 支持Windows 10+, 主流图像格式

## 技术风险与对策

1. **C++集成复杂度**: 使用pybind11简化绑定
2. **算法性能**: 分阶段优化，先实现后优化
3. **UI响应性**: 异步计算，避免阻塞UI线程
4. **内存占用**: 大图像分块处理，及时释放资源
