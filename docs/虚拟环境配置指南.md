## 虚拟环境信息

### 基本配置
- **虚拟环境目录：** `venv/`

- **pip版本：** 25.1.1 (最新)
- **环境类型：** 独立环境 (include-system-site-packages = false)

### 环境路径
```
项目根目录/
├── venv/                    # 虚拟环境目录
│   ├── Scripts/            # Windows脚本目录
│   │   ├── activate        # 激活脚本 (bash)
│   │   ├── activate.bat    # 激活脚本 (cmd)
│   │   ├── Activate.ps1    # 激活脚本 (PowerShell)
│   │   ├── python.exe      # Python解释器
│   │   └── pip.exe         # 包管理器
│   ├── Lib/               # 库文件目录
│   └── pyvenv.cfg         # 环境配置文件
```

## 使用方法

### 1. 激活虚拟环境

#### Windows PowerShell
```powershell
# 激活虚拟环境
venv\Scripts\Activate.ps1

# 或者
venv\Scripts\activate
```

#### Windows CMD
```cmd
# 激活虚拟环境
venv\Scripts\activate.bat
```

#### 验证激活
激活成功后，命令提示符前会显示 `(venv)`：
```
(venv) PS G:\MyaProject\mya_sdf_Tools>
```

### 2. 运行应用程序

#### 使用虚拟环境Python
```powershell
# 直接使用虚拟环境的Python
venv\Scripts\python.exe main.py

# 或者激活后使用
venv\Scripts\activate
python main.py
```

#### 使用启动脚本
```powershell
# 使用专用启动脚本
venv\Scripts\python.exe start_app.py
```

### 3. 包管理

#### 安装新包
```powershell
# 激活环境后
venv\Scripts\activate
pip install 包名

# 或直接使用
venv\Scripts\pip.exe install 包名
```

#### 更新包
```powershell
venv\Scripts\pip.exe install --upgrade 包名
```

#### 查看已安装包
```powershell
venv\Scripts\pip.exe list
```

#### 导出依赖
```powershell
venv\Scripts\pip.exe freeze > requirements.txt
```

### 4. 退出虚拟环境
```powershell
deactivate
```

## 常见问题解决

### 1. 激活失败
**问题：** PowerShell执行策略限制
**解决：** 
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 2. 包安装失败
**问题：** 网络或权限问题
**解决：**
```powershell
# 使用国内镜像
venv\Scripts\pip.exe install -i https://pypi.tuna.tsinghua.edu.cn/simple/ 包名

# 升级pip
venv\Scripts\python.exe -m pip install --upgrade pip
```

### 3. 环境损坏
**问题：** 虚拟环境文件损坏
**解决：**
```powershell
# 删除虚拟环境
Remove-Item -Recurse -Force venv

# 重新创建
python -m venv venv
venv\Scripts\pip.exe install -r requirements.txt
```
