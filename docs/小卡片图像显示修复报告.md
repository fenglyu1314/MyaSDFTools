# 小卡片图像显示修复报告

## 问题描述

用户反馈区域1（图像导入）和区域2（单张SDF预览）中的小卡片预览图片显示不全，无法完整显示整张图片。

## 问题分析

### 根本原因
1. **尺寸不匹配**：图像标签设置为80x80像素，但图像缩放到100x100像素
2. **缺少居中对齐**：图像没有正确居中显示在标签中
3. **缩放逻辑错误**：缩放尺寸超出了容器尺寸

### 具体问题位置

#### 区域1：图像导入卡片 (`src/ui/image_card_widget.py`)
```python
# 问题代码
self.thumbnail_label.setFixedSize(80, 80)  # 标签尺寸80x80
scaled_pixmap = pixmap.scaled(100, 100, ...)  # 但图像缩放到100x100
```

#### 区域2：SDF卡片 (`src/ui/sdf_card_widget.py`)
```python
# 问题代码  
self.sdf_preview_label.setFixedSize(80, 80)  # 标签尺寸80x80
scaled_pixmap = sdf_image.scaled(100, 100, ...)  # 但图像缩放到100x100
```

## 修复方案

### 1. 统一尺寸设置
将图像缩放尺寸调整为与标签尺寸一致：

#### 修复图像导入卡片
```python
def _load_thumbnail(self):
    """加载缩略图"""
    # 修复前：缩放到100x100
    # scaled_pixmap = pixmap.scaled(100, 100, ...)
    
    # 修复后：缩放到80x80，与标签尺寸一致
    scaled_pixmap = pixmap.scaled(
        80, 80, 
        Qt.KeepAspectRatio, 
        Qt.SmoothTransformation
    )
    self.thumbnail_label.setPixmap(scaled_pixmap)
    # 确保图像居中显示
    self.thumbnail_label.setAlignment(Qt.AlignCenter)
```

#### 修复SDF卡片
```python
def set_sdf_preview(self, sdf_image: QPixmap):
    """设置SDF预览图"""
    # 修复前：缩放到100x100
    # scaled_pixmap = sdf_image.scaled(100, 100, ...)
    
    # 修复后：缩放到80x80，与标签尺寸一致
    scaled_pixmap = sdf_image.scaled(
        80, 80, 
        Qt.KeepAspectRatio, 
        Qt.SmoothTransformation
    )
    self.sdf_preview_label.setPixmap(scaled_pixmap)
    # 确保图像居中显示
    self.sdf_preview_label.setAlignment(Qt.AlignCenter)
```

### 2. 添加居中对齐
确保图像在标签中居中显示，避免偏移或裁剪。

### 3. 保持宽高比
使用`Qt.KeepAspectRatio`确保图像不会变形，完整显示原始图像的内容。

## 技术细节

### 关键修改点
1. **尺寸统一**：图像缩放尺寸 = 标签尺寸 = 80x80
2. **居中对齐**：`setAlignment(Qt.AlignCenter)`
3. **保持比例**：`Qt.KeepAspectRatio`
4. **平滑缩放**：`Qt.SmoothTransformation`
