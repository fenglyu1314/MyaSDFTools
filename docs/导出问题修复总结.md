# SDF工具导出问题修复总结

## 问题概述

用户反馈了两个关键问题：
1. **导出图像和预览不一致**：导出的图像是彩色的（RGB三通道），而预览显示的是灰度图像
2. **打开目录功能错误**：导出后选择打开目录时，无法正确打开保存图片的目录

## 修复方案

### ✅ 问题1：导出图像颜色不一致 - 已修复

**问题原因**：
- 预览：使用灰度模式显示SDF数据
- 导出：使用默认的`colormap='viridis'`彩色映射

**修复方法**：
在导出时明确指定使用灰度模式：

```python
# 单个SDF导出 (src/ui/main_window.py:1217)
success = ImageUtils.save_sdf_as_image(self.sdf_result, file_path, colormap='gray', quality=95)

# 批量SDF导出 (src/ui/main_window.py:1580)
if ImageUtils.save_sdf_as_image(sdf_result, str(output_path), colormap='gray'):
```

**修复效果**：
- ✅ 导出的图像现在为灰度模式(L)
- ✅ 预览和导出完全一致
- ✅ 符合SDF数据的本质特性

### ✅ 问题2：打开目录功能错误 - 已修复

**问题原因**：
- 使用的explorer命令调用方式不够可靠
- 缺少有效的备用方案

**修复方法**：
参考用户提供的代码，采用更可靠的方法：

```python
# Windows系统优先使用os.startfile()
if system == "Windows":
    if path_obj.is_file():
        # 选中文件
        os.system(f'explorer /select,"{target_path}"')
    else:
        # 打开文件夹
        try:
            os.startfile(folder_path)  # 主要方案
        except:
            os.system(f'explorer.exe "{folder_path}"')  # 备用方案
```

**修复效果**：
- ✅ 使用`os.startfile()`作为主要方案，更可靠
- ✅ 保留`os.system()`作为备用方案
- ✅ 跨平台兼容性更好
- ✅ 错误处理更完善

## 技术改进点

### 1. 颜色映射统一
- **灰度模式**：`colormap='gray'` → PIL模式'L'
- **数据一致性**：预览和导出使用相同的颜色处理逻辑
- **用户体验**：所见即所得，避免混淆

### 2. 文件夹打开优化
- **方法1**：`os.startfile()` - Python内置，最可靠
- **方法2**：`os.system()` - 系统命令，备用方案
- **方法3**：`subprocess.run()` - 跨平台兼容

### 3. 路径处理改进
- 使用`Path().resolve()`获取绝对路径
- 正确处理文件和文件夹的区别
- 路径字符串格式化更安全
