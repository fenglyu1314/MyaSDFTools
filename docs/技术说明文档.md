# SDF工具技术说明文档

## 项目概述

**SDF工具**是一个专为二次元渲染设计的脸部SDF (Signed Distance Field) 生成工具，支持多角度光照图像混合和实时预览。项目采用Python + PySide6构建GUI界面，核心算法支持Python和C++双重实现，确保高性能计算。

### 主要特性

- 🖼️ **多角度SDF生成**: 导入多张不同角度的脸部光照图像，生成混合SDF
- 🎯 **单张图SDF**: 快速将单张黑白图转换为SDF格式  
- 🔄 **实时预览**: 滑竿控制光照角度，实时预览SDF效果
- ⚡ **高性能算法**: 支持C++加速的8SSEDT算法
- 🎨 **现代界面**: 基于PySide6的直观GUI界面
- 📊 **性能监控**: 显示计算时间和性能指标

### 技术栈

- **UI框架**: PySide6 (Qt6)
- **图像处理**: OpenCV, Pillow, NumPy
- **核心算法**: Python + C++ (可选)
- **构建系统**: CMake + pybind11
- **包管理**: pip + requirements.txt

**归一化策略**:

## 故障排除

### 常见问题

1. **C++扩展编译失败**
   - 确保安装了C++编译器 (Visual Studio/GCC)
   - 检查CMake和pybind11是否正确安装
   - 可以跳过C++扩展，使用Python实现

2. **图像导入失败**
   - 检查图像格式是否支持 (PNG, JPG, BMP等)
   - 确保图像文件没有损坏
   - 检查文件路径是否包含特殊字符

3. **内存不足**
   - 减小图像尺寸或降低最大距离参数
   - 在配置中调整内存限制
   - 关闭其他占用内存的应用程序

4. **计算速度慢**
   - 启用C++后端加速
   - 调整线程数设置
   - 减小图像尺寸或参数值
